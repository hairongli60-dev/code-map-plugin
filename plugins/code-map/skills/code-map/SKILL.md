# code-map — 让代码有地方可查

## 解决什么

agent 跑任务会生成一堆脚本，散在项目里、临时目录里、会话里。
等用户回头看，只记得"当时好像写过个处理 ERP 的脚本"，但找不到。

这个 skill 做两件事：

1. 把项目里**所有代码**变成一张可读的地图 `CODE_MAP.md`（入口、用途、依赖、孤儿）
2. 每次新代码进来，**增量**更新地图，不重扫已经写好的部分

配套的 hook 在写入时就拦截"往临时目录写代码"的行为，从源头减少失踪文件。

## 四步

### 1. 扫一次，拿到清单（一条命令）

```bash
bash "${CLAUDE_PLUGIN_ROOT}/skills/code-map/scripts/scan.sh"
```

`CLAUDE_PLUGIN_ROOT` 没值就直接用本 skill 目录下的 `scripts/scan.sh`（不要为此翻遍磁盘找）。

输出包含：已跟踪代码（路径/行数/最后改动）、**未跟踪的新代码**、数据产物、入口脚本、目录分布。
这一步已经足够回答"有哪些文件"，**不要再用 ls / find / tree 复核一遍**。

### 2. 判断要不要增量

- 项目根**没有** `CODE_MAP.md` → 全量生成
- **有** → 读它开头的 `> HEAD: xxx`，和本次 scan 输出的 HEAD 比对
  - 相同 → 只补 `UNTRACKED` 部分，其余不动，直接跳到第 4 步
  - 不同 → 只重写 `last-commit` 变了的那些行 + 新文件

### 3. 描述每个脚本（只读开头，不读全文）

对每个**还没有描述**的代码文件：

```bash
head -30 <file>          # docstring / imports / 第一个函数签名，够判断用途
grep -nE '^(def|class|function|func) ' <file> | head -10   # 需要看结构时
```

红线：**不要 Read 整个文件**。一个脚本的用途在前 30 行里，读完只是浪费上下文。
看不懂时再 grep 关键词，仍然不要通读。

### 4. 写 CODE_MAP.md

写到项目根目录，格式固定：

```markdown
# CODE_MAP

> 由 code-map 生成 · <日期> · HEAD: <sha>
> 更新：对 AI 说「更新代码地图」

## 入口
| 文件 | 行数 | 用途 | 最后改动 |
|---|---|---|---|
| scripts/run_pipeline.py | 214 | 主流程：读原始数据 → 预处理 → 出指标 | 2026-11-10 |

## 模块
| 文件 | 行数 | 用途 |
|---|---|---|

## 数据与产物
| 路径 | 类型 | 由谁生成 |
|---|---|---|

## 孤儿 / 可疑
- `scripts/old_analysis.py` — 没有任何文件引用，最后改动 2025-03，疑似废弃

## 未跟踪
- `scripts/tmp_check.py` — 9 行的一次性排查脚本，建议删除或并入 tests/
```

## 增量更新的准确含义

地图**不是**后台自动维护的。真实分工是：

| 谁 | 保证什么 | 成本 |
|---|---|---|
| `git ls-files` / `git status` | 新文件一定会出现在清单里，不会漏 | 零 |
| 本 skill（按需运行） | 文件**干什么**、谁引用谁、哪些该删 | 一次几 k token |
| `guard-temp-write.sh` hook | 脚本不会被写到项目外 | 零 |

所以"新代码自动加入"靠 git，"读懂新代码"靠你喊一声更新。**不要承诺实时自动地图**。

## 孤儿判定

只看**入口脚本**（scan 输出 ENTRYPOINTS 段）有没有被别处引用，不要全库互相 grep：

```bash
grep -rn --include='*.py' --include='*.sh' "script_name" . | grep -v "^./scripts/script_name"
```

零引用 + 最后改动超过 6 个月 → 列进"孤儿/可疑"，**只建议，不删除**。

## 什么时候不要用

- 只是想知道某个函数在哪 → 直接 `Grep`，不用建地图
- 一次性脚本问答 → 直接回答
- 项目已经有一份维护良好的 README 描述结构 → 别重复造

## 一句话

**git 保证不漏，扫描保证可读，地图只在需要时重新生成。**
